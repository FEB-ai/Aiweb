# 「신경과학」 강의 소개 사이트

고려대학교 의과학과 「신경과학」 강의를 소개하는 웹사이트입니다.
**서버 없이** 브라우저에서 바로 열리는 정적 사이트이며, 설치할 프로그램이 없습니다.

---

## 1. 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 뼈대. 이 파일을 열면 사이트가 보입니다. |
| `config.js` | **사이트의 모든 내용**(글·일정·메뉴·공지·과제 등). 내용은 여기만 고치면 됩니다. |
| `styles.css` | 디자인. 맨 위 `:root` 의 색 값만 바꾸면 분위기가 바뀝니다. |
| `app.js` | 설정을 읽어 화면을 그리고 움직이는 코드 |
| `admin.js` | 관리자 화면 코드 |
| `images/` | 로고(`logo.webp`), 교수자 사진(`professor.jpg`) 등을 넣는 폴더 |
| `fonts/` | 사이트 글씨체 — 고려대 백주년기념체(`KUCentennial.otf`, `.ttf`). **배포할 때 함께 올려야 합니다.** |
| `README.md` | 이 안내 문서 |

> `.claude/` 폴더는 제작 중 미리 보기용 파일, `고려대 백주년기념체/` 폴더는 글씨체 원본, `apps-script/` 폴더는 구글 시트에 붙여 넣을 코드입니다. 셋 다 배포할 때 올리지 않아도 됩니다.

---

## 2. 사이트 열기

- **가장 쉬운 방법:** `index.html` 을 더블클릭합니다. (Chrome 또는 Edge 권장)
- 확인용 주소 꼬리표
  - `index.html?welcome` — 첫 방문 폭죽과 안내 팝업을 다시 봅니다.
  - `index.html?reset` — 이 브라우저에 저장된 관리자 수정본을 버리고 `config.js` 원본으로 돌아갑니다.

## 3. 화면 구성

위에서 아래로 한 페이지를 읽는 구조입니다. 헤더 메뉴를 누르면 해당 위치로 이동합니다.

1. **첫 화면** — 배지, 제목, 부제, 설명, 수강 신청·커리큘럼 보기 버튼, 한눈에 보기(일정·시간·방식·대상), 통계 카드
2. **공지사항** — 관리자 화면에서 올린 공지 (중요 공지가 맨 위)
3. **프로그램 소개** — 강의 내용, 좌우로 넘기는 특징 슬라이드(버튼·점·손가락·키보드 ← →)
4. **커리큘럼** — 15주 펼침 목록(날짜·시간·장소·학습 내용·참고 영상·과제·마감 카운트다운), 월간 수업 달력(수업·과제 마감·일정·공휴일)
5. **우수 과제 포트폴리오** — 구글 드라이브로 등록한 과제물 카드, 분류별 보기
6. **수강 안내** — 수강 대상, 실습 AI 도구, 평가 방법, 준비물
7. **참여하기** — 설문(막대그래프), 수강 신청서(빠진 항목 안내), 설문 히스토리 표
8. **내 강의실** — 수강생 로그인, 출석 체크, 과제 제출
9. **FAQ** — 접이식 질문과 답
10. **교수자(푸터)** — 교수자 소개, 연락처, 저작권 문구

휴대폰에서는 오른쪽 위 ☰ 버튼으로 메뉴를 열고 닫습니다.

## 4. 내용 고치는 방법

### 방법 A — `config.js` 를 직접 고치기
메모장이나 VS Code 로 `config.js` 를 열어 **따옴표 안의 글자만** 바꾸고 저장한 뒤 새로고침(F5)합니다.
쉼표(`,`)와 괄호가 지워지지 않게 주의하세요.

자주 고치는 곳

| 고칠 내용 | 위치 |
|---|---|
| 첫 수업일 (15주 날짜가 7일 간격으로 자동 계산) | `curriculum.schedule.firstClass` |
| 수업 시간·장소 (첫 화면·목록·달력에 함께 반영) | `curriculum.schedule.time`, `place` |
| 한 주만 날짜가 다를 때 | 그 주차에 `date: "2026-05-07"` 추가 |
| 과제 | 그 주차의 `assignment` (`due` 는 `"2026-03-23T23:59"` 형식) |
| 과제를 LMS·구글 폼으로 받기 | `assignment.submitUrl` 에 주소 |
| 공휴일 | `curriculum.holidays` (수업일과 겹치면 ⚠ 표시) |
| 로고·교수자 사진 | `site.logo`, `instructor.photo` 에 `images/파일이름` |

### 방법 B — 관리자 화면에서 고치기
1. 오른쪽 위 **🔒 자물쇠**를 누릅니다.
   - 처음에는 비밀번호가 없으므로 **비밀번호를 직접 만듭니다.** (6자 이상)
2. **내용 편집** 탭에서 섹션을 고르고 바로 고칩니다. 항목 추가·삭제·순서 변경(↑↓)도 됩니다.
3. 위의 **저장하고 적용**을 누릅니다. → *이 브라우저에만* 반영됩니다.
4. **모든 방문자에게 반영하려면:** `설정 파일·보안` 탭 → **설정 파일 내려받기 (config.js)** →
   사이트 폴더의 `config.js` 를 내려받은 파일로 바꾸고 다시 올립니다.

> 수정이 반영되는 순서
> ① 관리자 화면에서 수정 → ② 저장하고 적용 (내 브라우저에만 반영)
> ③ 설정 파일 내려받기 → ④ 사이트 폴더의 `config.js` 교체 후 다시 올리기 (모든 방문자에게 반영)

---

### 방법 C — 본문에서 바로 고치기 (관리자로 로그인했을 때)
관리자로 로그인하면 아래 영역에 노란 점선 버튼(**✏️ 수정 · 🗑 삭제 · ↑↓ · + 추가**)이 보이고, 그 자리에서 바로 고칠 수 있습니다.

| 영역 | 할 수 있는 일 |
|---|---|
| 커리큘럼 → 주차별 학습 | 주차 추가·수정·삭제·순서 변경 (날짜·시간·장소·학습 내용·참고 영상·과제) |
| 커리큘럼 → 월간 수업 달력 | 수업 일정 기본값(첫 수업일·시간·장소), 날짜별 일정(휴강·보강·특강·시험·행사·기타) 추가·수정·삭제 |
| 우수 과제 포트폴리오 | 구글 드라이브 주소로 과제물 등록, 수정·삭제·순서 변경, 분류 목록 |
| 참여하기 | **설문 추가**, 설문 히스토리 표에서 **열기·수정·삭제** (진행 중/마감), 제목·안내 문구 |
| 자주 묻는 질문 | 질문 추가·수정·삭제·순서 변경 |

- 각 섹션 제목 아래 **✏️ 제목·소개 수정**으로 섹션 제목과 소개 문구도 고칠 수 있습니다.
- 저장하면 바로 이 브라우저에 반영되고, 보던 위치로 돌아옵니다.
- 화면 왼쪽 아래 **편집 막대**
  - **방문자 화면으로 보기**: 편집 버튼을 숨기고 미리 봅니다.
  - **관리자 화면**
  - **config.js 내려받기**: 모든 방문자에게 반영할 때 사용합니다.
- 설문 히스토리 표의 참여 수는 이 브라우저에서 집계한 값입니다. 설문의 선택지를 바꾸면 그 설문의 투표 결과는 초기화됩니다.

## 4-1. 강의 관리 기능 (서버 없이 작동)

### 구글 시트 연동 — 기록을 한 곳에 모으기
신청서·출석·과제 제출·설문 응답이 **교수자의 구글 시트**로 모이고, 과제 파일은 **구글 드라이브 '강의 과제 제출' 폴더**에 저장됩니다.

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 사이트 폴더의 `apps-script/Code.gs` 내용을 **모두 복사해 붙여 넣고** 저장합니다.
4. 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**
   - 실행 사용자: **나** · 액세스 권한: **모든 사용자** → 배포 → 권한 허용
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해
   `config.js` 의 `sheets.endpoint` 에 넣습니다. (또는 관리자 화면 → 내용 편집 → 구글 시트 연동)
6. 사이트를 다시 올리면 끝. 시트에 `수강신청 · 출석 · 과제제출 · 설문응답` 탭이 자동으로 생깁니다.

> 웹 앱 주소를 아는 사람은 누구나 기록을 보낼 수 있으니 주소를 따로 공유하지 마세요. 코드를 고치면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.

### 출석 코드 / QR
- 관리자 화면 → **수강생 명단** 탭 → **출석 코드 사용하기** → 저장하고 적용 → **config.js 내려받아 교체**.
- 수업 시간에 본문 편집 막대의 **📺 출석 코드**(또는 내 강의실의 '출석 코드 화면 띄우기')로 교실 화면에 띄웁니다.
- 4자리 코드는 **1분마다 바뀌고**, QR 을 찍으면 코드가 입력된 채로 내 강의실이 열립니다. (QR 은 사이트를 배포한 뒤 표시)
- 학생은 로그인 → 코드 입력 → 출석 체크. **5번 틀리면 그날은 잠깁니다.**
- 실제 운영에서는 `classroom.testMode` 를 `false` 로 바꿔야 수업일에만 출석됩니다.

### 논문 발표 배정표 · 주차별 자료실
- 커리큘럼 아래 **논문 발표 배정표**: 주차·발표자·논문·논문 주소. 해당 주차 목록에도 '논문 발표'로 표시됩니다.
- 각 주차의 **강의 자료**: 슬라이드·PDF·데이터 링크. 주소를 비워 두면 '준비 중'으로 보입니다.
- 둘 다 관리자로 로그인하면 본문에서 바로 추가·수정·삭제합니다.

### 내 캘린더에 추가 (.ics)
월간 수업 달력 오른쪽 위 **📅 내 캘린더에 추가** → 15주 수업(시간·장소)·과제 마감·휴강/특강 일정이 담긴 파일을 내려받습니다.
구글 캘린더(설정 → 가져오기), 아웃룩, 아이폰 캘린더에서 열면 한 번에 추가됩니다.

### 수업 만족도 설문
참여하기 설문 히스토리에 **[중간 강의 평가] · [기말 강의 평가]** 가 '준비 중'으로 들어 있습니다(방문자에게는 숨김).
쓸 때 ✏️ 수정 → 상태를 **진행 중**으로 바꾸면 공개됩니다.

## 5. 관리자 화면 기능

| 탭 | 할 수 있는 일 |
|---|---|
| 내용 편집 | 사이트 정보와 모든 섹션 내용 수정, 항목 추가·삭제·순서 변경 |
| 공지 | 공지 올리기, 중요 공지 고정, 순서 변경·삭제 |
| 수강생 명단 | 학번 목록 붙여 넣어 등록, 등록 여부 확인·삭제, **수강 코드 바꾸기** |
| 내역 확인 | 출석·과제 제출·수강 신청 내역 표 보기, **엑셀용 파일(CSV)** 내려받기 |
| 설정 파일·보안 | `config.js` 내려받기·불러오기, 이 브라우저 수정본 되돌리기, 관리자 비밀번호 바꾸기 |

- 비밀번호·수강 코드·수강생 명단은 **지문(SHA-256 해시)으로만** 저장됩니다. 원문은 어디에도 남지 않습니다.
- CSV 파일은 엑셀에서 한글이 깨지지 않게 저장됩니다.

## 6. 배포 전 점검

- [ ] 관리자 비밀번호를 만든 상태로 내려받은 `config.js` 로 교체했는지
- [ ] 수강 코드를 바꿨는지 (관리자 화면 → 수강생 명단 → 수강 코드 바꾸기)
- [ ] 수강생 명단을 등록했는지 (비어 있으면 수강 코드를 아는 누구나 로그인 가능)
- [ ] `classroom.testMode` 를 `false` 로 바꿨는지 (`true` 면 수업일이 아니어도 출석 체크가 됩니다)
- [ ] (선택) 구글 시트 연동 주소(`sheets.endpoint`)를 넣었는지, 출석 코드를 켰는지
- [ ] 포트폴리오 샘플 3개를 실제 과제물로 바꿨는지 (드라이브 공유: '링크가 있는 모든 사용자 – 뷰어')
- [ ] `[예시]` 표시가 붙은 내용(강의 설명·커리큘럼·과제·FAQ·교수자·팝업 문구 등)을 실제 내용으로 바꿨는지
- [ ] 수업일이 공휴일과 겹치지 않는지 (예: 10주차 5월 5일 어린이날)
- [ ] `images` 폴더와 `fonts` 폴더를 함께 올렸는지

## 7. 배포 방법

### Netlify Drop (가장 쉬움)
1. https://app.netlify.com/drop 에 접속합니다.
2. 사이트 폴더(`index.html` 이 들어 있는 폴더)를 통째로 끌어다 놓습니다.
3. 바로 주소가 만들어집니다. 수정할 때는 같은 방법으로 다시 올립니다.

### GitHub Pages
1. GitHub 에 새 저장소를 만들고 사이트 파일을 모두 올립니다.
2. 저장소 **Settings → Pages** 에서 Branch 를 `main` / `(root)` 로 고르고 저장합니다.
3. 잠시 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다.

### 학교·학과 웹 서버
사이트 폴더의 파일을 웹 폴더에 그대로 올립니다.

## 8. 한계 (서버 없는 사이트)

| 기능 | 지금 | 실제 운영에 필요한 것 |
|---|---|---|
| 투표 | 화면에는 이 브라우저의 표만 집계 (**시트 연동 시 응답은 시트에 모임**) | 서버에서 합산 |
| 수강 신청서 | 이 브라우저에 저장 → **시트 연동 시 구글 시트로** | — |

화면에도 "시범 운영 중" 안내가 표시됩니다.
출석·성적·과제는 학교 LMS 에 맡기고, 이 사이트는 소개·커리큘럼·공지에 집중하는 방법도 있습니다.

## 9. 문제 해결

- **고친 내용이 다른 사람에게 보이지 않음** — 관리자 화면의 '저장하고 적용'은 내 브라우저에만 반영됩니다. 설정 파일을 내려받아 `config.js` 를 교체하고 다시 올리세요.
- **고친 뒤 화면이 이상해짐** — 주소 끝에 `?reset` 을 붙여 엽니다. 이 브라우저의 수정본을 버리고 `config.js` 원본으로 돌아갑니다.
- **관리자 비밀번호를 잊음** — `config.js` 에서 `admin.passwordHash` 값을 `""` 로 비우고 다시 올린 뒤, 자물쇠를 눌러 새로 만듭니다. (이 브라우저에 수정본이 있으면 `?reset` 도 함께)
- **수업 날짜가 공휴일과 겹침** — 해당 주차에 `date` 를 넣어 날짜를 옮기거나, 공지로 휴강을 안내합니다.
- **사진·로고가 보이지 않음** — `images` 폴더를 함께 올렸는지, 설정의 경로(`images/파일이름`)가 맞는지 확인합니다.
- **로그인이 안 됨** — 최신 Chrome 또는 Edge 로 여세요. 수강 코드가 맞는지, 명단에 학번이 있는지 확인합니다.
